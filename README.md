# 厚板多层多道焊接离线编程系统

浏览器端的厚板坡口多层多道排道与六轴机器人离线编程系统。纯 TypeScript + three.js，
工件/工艺/方案全部持久化在浏览器 IndexedDB，无需后端服务。

## 技术栈

- Vite + TypeScript（strict）+ three.js，零 UI 框架（手写 DOM 构建层）
- 核心算法（`src/core/`）与 UI（`src/ui/`）严格分层，算法不依赖 three.js / DOM，可独立单测
- Vitest 单元测试 22 项，覆盖两条硬性验收指标

## 启动

```bash
npm install
npm run dev      # 开发服务器
npm test         # 核心算法测试（22 项）
npm run build    # 类型检查 + 生产构建到 dist/
npx tsc --noEmit # 严格类型检查
```

## 六个功能页面

| 路由 | 页面 | 能力 |
| --- | --- | --- |
| `#workpiece` | 工件库 | 程序生成动臂箱体/斗杆筋板/变截面对接三类典型件；坡口形式、板厚、角度、钝边、间隙、余高等全参数可编辑；激光寻位间隙 CSV 导入 |
| `#planning` | 坡口排道 | V/X/U/角焊缝截面自动多层多道排布；每道给出工作角、行走角、焊丝指向偏移、电流/电压/焊速/摆宽；面积闭环 3% 审计；变间隙逐段重排 |
| `#torch` | 焊枪姿态 | 双轴变位机协调（平焊/船形）、六轴逆解、关节限位/奇异点警告、OBB 碰撞检测标红、自动抬枪避碰过渡路径 |
| `#simulation` | 离线仿真 | 时间轴拖动/播放，机器人+变位机联动，焊道扫掠网格逐道生长，按摆动频率/焊速生成鱼鳞纹 |
| `#forming` | 焊道成形 | 侧壁未熔合/夹渣谷角/层间未熔合自动圈注；逐道层间温度与热输入曲线、超温等待时间 |
| `#card` | 工艺卡 | 多方案对比（焊道数/熔敷量/工时）、机器人程序文本导出、带截面图 HTML 工艺卡导出 |

## 两条硬性验收指标（已自动化测试）

1. **排道面积误差 ≤3%**：`test/planner.test.ts` 对四种坡口形式逐种校验，
   排道熔敷总面积与坡口+余高需求面积误差全部 ≤3%。闭环逻辑见 `src/core/planner.ts`，
   先调盖面道、再全道等比、最后保底等比收口，全过程记录调整动作。
2. **FK(IK()) 位置回差 ≤0.1mm**：`test/robot.test.ts` 对多组关节角做正解→逆解→正解闭环，
   实测回差普遍 0.01mm 量级；同时校验姿态误差、工作空间不可达、腕部奇异警告、关节限位。

## 核心模块说明（`src/core/`）

- `geometry.ts` / `groove.ts`：2D 几何与 V/X/U/角焊缝截面多边形（含余高抛物弧）
- `wps.ts`：焊接工艺参数与熔敷面积（由送丝速度、焊丝直径、熔敷效率、焊速推导）、焊道当量几何
- `planner.ts`：水平切片多层多道排布 + 面积闭环审计 + 变间隙分段
- `robot.ts`：修改 DH 正解；两级数值逆解（手臂 DLS 收敛腕心 + 数值雅可比腕部姿态）；雅可比奇异值分析
- `positioner.ts`：双轴变位机网格搜索协调，法向对齐世界 Z（平焊）/45°（船形）
- `collision.ts`：工件 OBB 与焊枪胶囊碰撞、抬枪+横向搜索自动避碰
- `defects.ts`：侧壁熔合、谷角夹渣、层间搭接缺陷判定
- `thermal.ts`：集总参数层间温度模型、热输入、超温等待反解
- `trajectory.ts`：关键帧轨迹与机器人程序文本导出
- `workpieces.ts`：三类程序化工件与焊缝路径帧（直线/圆弧）
- `db.ts`：IndexedDB 版本化封装（workpieces/wps/schemes/programs/gaps 五个仓库）

## 工程模型的边界与标定建议

层间温度用的是集总参数近似（温升系数、冷却时间常数均为默认经验值，见 `wps.ts` 的
`defaultThermal`），用于方案阶段的趋势判断和等待时间估算；落地到现场前应按实测热循环曲线
标定这两个系数。逆解为数值方法，单次求解约亚毫秒~毫秒级，已用多初值覆盖不同构型，
但极端奇异位姿仍可能需要人工给定种子（`solveIK(target, { preferred })`）。
