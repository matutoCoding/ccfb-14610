# 厚板多层多道排道与焊接机器人离线编程系统

面向工程机械厚板焊缝（挖机动臂、斗杆等十几二十道焊）的浏览器端离线编程系统。
纯前端实现：**TypeScript + three.js + IndexedDB**，无需后端，数据全部存浏览器本地。

## 启动

```bash
npm install
npm run dev        # 开发,默认 http://127.0.0.1:5180
npm run build      # 类型检查 + 生产构建
npx tsx src/core/selftest.ts   # 核心算法自检(43 项)
```

## 六个页面

| 页面 | 功能 |
|------|------|
| 工件库 | 程序生成动臂箱体/斗杆筋板/变截面对接厚板；坡口角度、钝边、间隙、板厚可改；激光寻位变间隙序列导入（CSV 或示例生成） |
| 坡口排道 | 按送丝速度/焊速守恒算单道熔敷面积，自底向上定量布道（根焊→填充→盖面），末道反解闭合；变间隙分段重算、大间隙自动加道；多方案对比 |
| 焊枪姿态 | 工作角/行走角实时驱动 6R 解析逆解；关节限位、腕/肘奇异警告；焊枪-工件碰撞检测标红；自动最短无碰过渡路径 |
| 离线仿真 | 时间轴拖动/播放，机器人+双轴变位机+焊枪联动，焊道逐道扫掠生长（带鱼鳞纹），生成机器人程序目标点 |
| 焊道成形 | 逐道熔深/侧壁接触弦长/道间熔合；侧壁未熔合、夹渣角自动圈注；层间温度累计、超限等待、热输入曲线 |
| 工艺卡 | 汇总每道电流/电压/焊速/摆宽/起收弧点；导出机器人程序文本、工艺卡文本、截面排道图 PNG |

## 两个硬指标（自检可复现）

1. **面积闭合 ≤3%**：名义熔敷面积按送丝体积流守恒
   `A道 = (πd²/4)·wfs·η / v焊`，整体半径二分微调 + 末道按剩余面积反解。
   实测各坡口形式（V/双V/单边Bevel/角缝/直边）误差 0.05%~2.94%。
2. **逆解→正解回代 ≤0.1mm**：6R 球形腕 8 组解析解，取限位内最优；
   实测 5 组姿态回代位置偏差均为 0.0000mm，姿态偏差 0.000°。

运行 `npx tsx src/core/selftest.ts` 可看到全部 43 项检查（含矩阵求逆、欧拉往返、
坡口面积解析核对、物料守恒、变间隙加道、不可达优雅失败、变位机平焊/船形、热模型超限等待）。

## 工程模型与简化约定

- 单道熔敷以等效圆表示，闭合口径与工厂工艺卡一致（重熔搭接为冶金过程，不重复扣面积）。
- 工件/夹具碰撞用 OBB 盒；焊枪前端 60mm（导电嘴+干伸长）允许进入坡口，只检测后段枪体。
- 变位机协调：长直缝（>1.2m）自动选平焊避免端点甩出臂展，短角缝用 45° 船形。
- 热过程为集总热容 + 指数冷却经验模型，冷却时间常数可在 WPS 中标定。
- 默认机器人臂展 1580mm、变位机基座距 900mm，均可在 `defaults.ts` 调整。
